# Comparative Analysis of Imperative Programming Languages

## 📌 Project Description

This project was developed for the Programming Paradigms course with the objective of performing a comparative analysis between imperative programming languages through the implementation of classic computer science problems.

The project compares the following languages:

- Python
- Go
- C#

The implementations were developed using object-oriented programming principles and benchmark metrics to evaluate characteristics such as execution time, code size, and implementation complexity.

---

# 🎯 Objectives

The main objective of this project is to analyze differences between imperative programming languages based on the implementation of classic computational problems.

The project evaluates:

- Execution performance
- Code organization
- File size
- Number of lines of code
- Comparative behavior between interpreted and compiled languages

---

# 🧠 Classic Problems Implemented

The following classical computational problems were implemented:

| Problem | Description |
|---|---|
| QuickSort | Recursive sorting algorithm based on divide and conquer |
| Towers of Hanoi | Recursive mathematical puzzle involving disk movement |
| Knapsack Problem | Dynamic programming optimization problem |
